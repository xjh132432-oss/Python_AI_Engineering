# Python 练手项目

学 Python 有一阵子了，这是跟着一个学习路线边学边写的代码。 
从最开始连 input 都搞不明白，到现在能写个小系统，中间踩了不少坑，也把每次报错都记了下来。

## 项目都在这里了

- 01-基础语法：猜数字，初版和函数版都留着
- 02-数据结构：成绩管理、待办事项，主要是练字典怎么用
- 03-文件操作：词云生成，词频统计，最简单的文件读写
- 04-文件持久化入门：通讯录，能把数据存下来了
- 05-日志系统与工程习惯：给通讯录加了日志，每次操作都能看到记录
- 06-终极综合项目-商品库存系统：把之前学的全串起来了，增删改查、统计、日志、模糊搜索都有

## 怎么跑

每个文件夹里都是独立的 .py 文件，直接运行就行，比如：

```bash
python 06-终极综合项目-商品库存系统/inventory_management.py
