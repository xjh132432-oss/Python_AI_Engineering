学 Python 到现在，踩过的坑都记在这了。

大部分都是自己手误，或者想当然以为能跑，结果报错。留个底，以后回头看看也挺有意思。


1. 猜数字的时候拿字符串和整数比大小

写 guess = input()，然后直接 if guess > target。
想都没想就写了，input 回来的本来就是字符串，random.randint 出来的是整数，两个比不了。
加了 int() 转一下才反应过来。

后来养成了习惯：所有 input 的数字都主动加 int，不管有没有提醒。


2. json.load 读空文件崩了

通讯录那个项目，第一次跑的时候文件是空的，json.load 直接报错 JSONDecodeError。
当时只处理了 FileNotFoundError，没考虑到文件存在但没内容的情况。
改成 except (FileNotFoundError, JSONDecodeError) 之后就好了。

现在知道了，文件存在和文件内容是两码事。


3. show_all 里报错说 groups 没定义

代码是从之前一个版本改过来的，抄的时候漏掉了 groups = {} 那句。
然后直接去 sorted(groups.keys())，肯定找不到。
补上就好了。

以后改代码还是得从头到尾顺一遍逻辑，不能只抄后半段。


4. f-string 里引号套引号，写错了

商品管理系统里打印表格那行，写的是 print(f"{line}\t{line["name"]}")。
外层双引号，里面的键名也是双引号，Python 分不清哪是哪了。
改成 print(f"{line}\t{line['name']}") 就正常了。

记住这个了，以后外层双引号，里面就用单引号。


5. 把变量名取成了 dict，后面报错了

不记得是哪个项目了，反正写了 dict = {}。
后面想用 dict() 转类型的时候直接报错，因为 dict 已经被我覆盖了。
之后就不用这些名字当变量了，改成 data、info 之类的。


6. 文件不存在的情况没处理

访客计数器那个小项目，第一次运行 count.txt 还不存在，直接 open 就崩了。
用 try except 包了一下，文件不存在就返回 0，问题解决。

现在凡是读写文件，都会下意识想想文件要是没有怎么办。


7. 拿下标去遍历字典，结果啥也没有

待办事项那个项目，写了 for i in range(len(task))，以为字典能和列表一样取下标。
跑了一下发现不行，才想起来字典得用 for key in task 或者 items() 来遍历。

列表和字典的区别，经过这一次算是彻底记住了。


其实这些错回头看看都挺傻的，但每改一个就记住了点东西。
以后还会踩新坑，到时候再接着记。
